# 학교생활기록부 내용 동일성 검토 도구

학교생활기록부 출력용 Excel 파일을 자동 정제한 뒤, 학생별 기재 내용의 동일성을 검토하는 **Streamlit 기반 로컬 웹 애플리케이션**입니다. 교과 세부능력 및 특기사항, 창의적체험활동상황, 자유학기활동상황, 행동특성 및 종합의견 양식을 자동 인식합니다.

> **개인정보 보호 안내**: 원본 학교생활기록부와 검토 결과에는 민감한 학생 정보가 포함될 수 있습니다. 원본 Excel, 정제 결과, 검토 결과 파일을 GitHub에 업로드하지 마십시오. 이 저장소에는 코드와 문서만 보관해야 합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 자동 양식 판별 | 파일명과 무관하게 제목·헤더를 분석하여 교과, 창체, 자유학기, 행동특성 양식을 구분합니다. |
| 출력 양식 정제 | 반복 머리글·푸터를 제거하고, 페이지 경계에서 나뉜 학생 기재 내용을 하나의 행으로 병합합니다. |
| 학생별 동일성 검토 | 전체 내용 완전 동일, 붙어 있는 연속 3문장 이상 동일, 전체 내용 유사도 95% 이상을 판정합니다. |
| 파일별·교차 검토 | 같은 파일 안의 학생을 비교하고, 여러 파일 업로드 시 첫 업로드 파일을 기준으로 교차 검토합니다. |
| 색상 미리보기 | 완전 동일은 빨강, 연속 3문장 이상 동일은 오렌지, 유사도 95% 이상은 파랑으로 표시합니다. |
| 색상 Excel 내보내기 | 동일성이 검출된 행을 파일별 검토 시트와 교차 검토 시트로 내보냅니다. |
| 성능 최적화 | 전체 내용 해시, 연속 3문장 해시, 토큰·길이 필터를 이용해 정밀 비교 대상을 줄입니다. |
| Windows EXE 제작 | Windows에서 배치 파일을 실행해 브라우저 기반 프로그램을 EXE로 만들 수 있습니다. |

## 동일성 검토 기준

| 우선순위 | 기준 | 판정 방식 | 표시 색상 |
| --- | --- | --- | --- |
| 1 | 전체 내용 완전 동일 | 두 학생의 전체 내용이 모두 완전히 같을 때 검출합니다. 이 경우 다른 기준에는 중복 분류하지 않습니다. | 빨간색 `#C00000` |
| 2 | 연속 3문장 이상 동일 | 두 학생 내용에서 순서가 유지된 붙어 있는 공통 문장이 3개 이상일 때 검출합니다. | 오렌지색 `#ED7D31` |
| 3 | 전체 내용 유사도 95% 이상 | 완전 동일이 아닌 전체 내용의 문자 단위 유사도가 95% 이상일 때 검출합니다. | 파란색 `#1F4E78` |

유사도는 의미 기반 판정이 아니라 문자 배열 기반의 정량 지표입니다. 따라서 조사·부사·활동명 등의 일부 차이는 검출될 수 있지만, 의미가 비슷하더라도 표현 방식이 크게 다르면 검출되지 않을 수 있습니다.

## 로컬 실행 방법

### 1. 저장소 내려받기

Git을 사용하는 경우 아래 명령으로 저장소를 내려받습니다. Git을 사용하지 않는 경우 GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.

```bash
git clone https://github.com/사용자아이디/저장소이름.git
cd 저장소이름
```

### 2. 가상환경 만들기

가상환경은 다른 Python 프로젝트와 패키지가 섞이지 않도록 분리하는 폴더입니다. Windows PowerShell에서는 아래 명령을 실행합니다.

```
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

PowerShell에서 실행 정책 오류가 발생하면, 같은 창에서 아래 명령을 한 번 실행한 뒤 다시 활성화 명령을 실행합니다.

```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 3. 필요한 패키지 설치

```
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
```

### 4. 프로그램 실행

```
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 주소창에 아래 주소를 입력합니다.

```
http://localhost:8501
```

프로젝트의 `.streamlit/config.toml`에는 `server.showEmailPrompt = false`와 `browser.gatherUsageStats = false`가 설정되어 있습니다. 따라서 Streamlit 최초 실행 시 이메일 입력 질문을 건너뛰고 사용 통계 수집도 비활성화합니다.[1] [2]

## 사용 방법

프로그램이 브라우저에서 열리면 `.xlsx` 파일을 하나 이상 업로드합니다. 비교과·교과·행동특성 파일을 함께 올려도 자동으로 정제합니다. 여러 파일을 올리는 경우 **첫 번째 파일이 교차 검토의 기준 파일**이 됩니다.

파일별 검토 탭에는 같은 파일 안의 학생별 비교 결과가 표시됩니다. 교차 검토 탭에는 첫 업로드 파일을 기준으로 뒤에 업로드한 파일의 결과가 표시됩니다. `색상 포함 검토 결과 다운로드 (.xlsx )` 버튼을 누르면 동일성이 검출된 행만 포함하는 결과 Excel 파일을 만들 수 있습니다.

동일성 검출 행이 없다는 안내는 분석 실패를 의미하지 않습니다. 현재 설정된 세 기준을 만족하는 학생 쌍이 없다는 의미이며, `동일성 검출 행만 표시`를 해제하면 분석된 전체 행을 확인할 수 있습니다.

## Windows EXE 만들기

Windows에서는 프로젝트 폴더 안의 `build_windows_exe.bat` 파일을 두 번 클릭하면 필요한 패키지와 PyInstaller가 설치되고 EXE가 생성됩니다. 결과 파일은 다음 경로에 만들어집니다.

```
dist\SchoolRecordReview.exe
```

EXE를 실행하면 로컬 Streamlit 서버가 시작되고 브라우저가 자동으로 열립니다. 실행 중에는 검은색 창을 닫지 마십시오. 프로그램을 종료하려면 해당 창을 닫으면 됩니다.

> Windows용 EXE는 반드시 **Windows 컴퓨터에서 제작**해야 합니다. EXE 제작과 실행의 상세 절차는 [`윈도우_EXE_제작_초보자가이드.md`](%EC%9C%88%EB%8F%84%EC%9A%B0_EXE_%EC%A0%9C%EC%9E%91_%EC%B4%88%EB%B3%B4%EC%9E%90%EA%B0%80%EC%9D%B4%EB%93%9C.md)를 참고하십시오.

PyInstaller는 `--onefile` 옵션으로 단일 실행 파일을 만들고 `--add-data` 옵션으로 앱 코드와 설정 파일을 함께 포함할 수 있습니다.[3]

## GitHub 업로드 전 개인정보 점검

GitHub에 올리기 전에 아래 유형의 파일이 저장소에 들어가지 않았는지 반드시 확인합니다.

| 업로드하면 안 되는 항목 | 이유 |
| --- | --- |
| 원본 학교생활기록부 `.xlsx` 파일 | 학생의 성명·번호·기재 내용 등 개인정보가 포함될 수 있습니다. |
| 정제된 결과 Excel 파일 | 원본에서 성명이 제거되더라도 재식별 위험이 있을 수 있습니다. |
| 동일성 검토 결과 Excel 파일 | 학생 번호와 기재 내용이 포함됩니다. |
| 임시 결과 폴더 `refined_all/`, `dist/`, `build/` | 개인정보 또는 용량이 큰 자동 생성 파일이 포함될 수 있습니다. |

저장소 최상위 폴더에 아래 내용을 포함한 `.gitignore` 파일을 추가하는 것을 권장합니다.

```
# 학생부 원본 및 검토 결과: GitHub에 업로드 금지
*.xlsx
*.xls
*.csv

# Python 및 Streamlit 생성 파일
__pycache__/
*.py[cod]
.venv/

# PyInstaller 생성 파일
build/
dist/
*.spec

# 정제·검토 결과 폴더
refined_all/
output/
```

이미 민감한 Excel 파일을 Git으로 추적했다면 파일을 삭제하기 전에 아래 명령으로 **Git 추적만 해제**합니다. 단, 이미 원격 GitHub에 올라간 민감한 파일은 저장소 이력에 남을 수 있으므로 기관의 보안 담당자에게 즉시 알리고 적절한 삭제 절차를 진행해야 합니다.

```bash
git rm --cached 파일이름.xlsx
git commit -m "민감한 Excel 파일 Git 추적 해제"
git push
```

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| `py` 명령을 찾을 수 없음 | `python --version`을 확인합니다. Python은 설치되어 있으나 Python Launcher만 없다면 명령의 `py`를 `python`으로 바꿉니다. |
| `ModuleNotFoundError` 오류 | 가상환경이 활성화되었는지 확인하고 `py -m pip install -r requirements.txt`를 다시 실행합니다. |
| 브라우저가 열리지 않음 | 직접 `http://localhost:8501`에 접속합니다. |
| `Port 8501 is already in use` 오류 | 기존 검은색 실행 창을 닫고 다시 실행합니다. 필요하면 작업 관리자에서 관련 `python.exe` 또는 `SchoolRecordReview.exe`를 종료합니다. |
| 이메일 입력 질문이 표시됨 | 최신 `.streamlit/config.toml`, `launcher.py`가 있는지 확인한 뒤 다시 실행하거나 EXE를 다시 제작합니다. |
| 동일성 검출 결과가 없음 | 분석은 완료되었지만 현재 기준을 충족하는 학생 쌍이 없을 수 있습니다. 전체 행 보기로 내용을 확인하고 필요하면 기준 완화 기능을 별도로 추가합니다. |
